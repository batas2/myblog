The architecture diagram was wrong by the next deploy. It always is.

I stopped blaming the people who did not update it about three years ago. A diagram on a wiki is a picture of the system, not a part of it. Nothing makes the picture change when the system does.

Every tool I have used treats that as a discipline problem. Remember to update the model. It is a structural one. Drawing tools give you something true on the day it was saved. Reverse-engineering tools read the code and cannot write back to it. Both leave you holding two artefacts and a promise to reconcile them.

The promise is what fails.

So I built the thing I wanted. Stemma is an architecture modelling tool with one heretical idea underneath it: the source code is the model database.

A model is C# records in Architecture/Architecture.cs, inside your own repository, and editing an element on the canvas is a Roslyn rewrite of that file. No export step to forget. No second copy. No proprietary format in the middle.

Everything rests on one guarantee, and it is the part I would attack first if somebody showed this to me. A canvas edit has to arrive as a diff containing only that edit. Rename a module and git diff reports the declaration and the references Roslyn can see, with nothing reordered, nothing reformatted, no comment lost and no blank line moved. The codebase carries a standing instruction about it: when the fidelity suite fails, the implementation is wrong, not the test.

What follows from that I did not anticipate. There is no runtime database at any layer. Storage is your Git working tree and nowhere else. So an architecture change arrives as a pull request. Blame works. Revert works. The model has a history, because Git already solved that and I did not have to.

The other half of this problem was never modelling. It is getting a room to agree. Story books are ordered pages that drive the canvas while you present, stored beside the model so the deck cannot go stale either, and for everyone who will never install it there is one self-contained HTML file that opens offline. No server, no login, no seat.

Honest position. A pet project, three months of evenings, not a company. The licence is PolyForm Noncommercial, which is source-available and not open source, and I would rather say that myself than have it pointed out. No roadmap owed to anyone, no sales call at the end.

If you have lived with the drift long enough to be cynical about it, you are the reader I want. The guarantee is the load-bearing part, so start there.
